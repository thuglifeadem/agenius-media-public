# agenius-media-public

Public image hosting for social media posts made by
[agenius-socialmedia-manager](https://github.com/thuglifeadem/agenius-socialmedia-manager).
Instagram downloads post images from here, so this repo must stay public.
Only finished post images belong here: no code, drafts or secrets.

Layout: `<account>/<yyyy-mm>/<post-id>-<n>.jpg`
